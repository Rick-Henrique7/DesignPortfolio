# Amanda — Designer Gráfica (esqueleto)

Projeto esqueleto criado com Vite + React + TypeScript + Tailwind.

Scripts:

```bash
npm install
npm run dev
```

Descrição:
- Estrutura de grid baseada na imagem fornecida.
- Seções criadas: Hero (com Musea), Segunda seção, Carousel, Tipografias, Logotipos.
- Não foram adicionadas imagens nem conteúdo — apenas placeholders e layout responsivo.
